# Proyecto IAW-web

Repositorio para las prácticas de **Implantación de Aplicaciones Web** del ciclo *ASIR*.

## Contenidos del proyecto

### Fases de trabajo (Lista ordenada)
1. Creación y clonación del repositorio remoto.
2. Creación de documentación en Markdown.
3. Publicación con GitHub Pages.

### Tecnologías empleadas (Lista no ordenada)
- Git y GitHub
- HTML5 y CSS3
- Markdown

## Enlace de referencia

Puedes consultar la guía oficial en [Documentación de GitHub](https://docs.github.com).
